# BLACK ZONE — Gaming Website

ملف الموقع الرئيسي هو `index.html`، والتصميم وCSS موجودان بداخله. التصميم أسود بطابع ألعاب مع أقسام PUBG والمحاكي، ومتجاوب مع الهاتف والكمبيوتر.

## قبل النشر
- استبدل رابط Discord التجريبي داخل `index.html`.
- رابط WhatsApp مضبوط على الرقم المرسل.
- عدّل أسماء المنتجات والأسعار والوصف بما يناسبك.

## النشر على GitHub Pages
1. ارفع `index.html` و`README.md` إلى جذر مستودع GitHub.
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch ثم `main` والمجلد `/ (root)`.
4. اضغط Save وانتظر ظهور رابط الموقع.
